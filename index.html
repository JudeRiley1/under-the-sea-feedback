QUICK GUIDE

Add your feedback

  1. Select a game tab. Choose Bugs or Improvements, then select Add.
  2. Enter your name when prompted, then paste a screenshot with Ctrl+V and write a description.
  3. Select Submit. Your feedback appears on that game’s board.

The Open view hides completed reports. Choose Complete or All statuses to see them again. Use All profiles to filter feedback by player. Only the administrator can delete reports.
