WELCOME ABOARD

A shared journal,
one discovery at a time.

  1. Choose Bugs or Improvements.

    The Add button opens a short GitHub report form. Sign in to GitHub if needed.

  2. Paste your screenshot, then describe it.

    Click the Screenshots field and press Ctrl+V, or drag an image into it. Give the report a short title.

  3. Submit and return to the journal.

    Click Refresh to see the shared entry. Thumbnails keep the table tidy; click one to expand it.

  4. Keep the report up to date.

    Open its details, then Edit / discuss on GitHub. Update the Status field or close a completed report. GitHub controls who can edit each report.

This is a public journal. Anyone with the link can read it. All reports and uploaded screenshots are public.
