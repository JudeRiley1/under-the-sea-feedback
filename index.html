    QUICK GUIDE

    Add your feedback

    1. Select a game tab. Choose Bugs or Improvements, then select Add.
    2. Paste a screenshot with Ctrl+V and write a description.
    3. Select Submit. Your feedback appears on that game’s board.

    Active feedback hides Done and Not planned reports. Use the status filter to see all reports or a specific status. Only the administrator can delete reports.
